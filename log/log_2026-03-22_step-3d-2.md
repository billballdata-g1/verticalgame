### **3️⃣ 修复关键 Bug：鞋子抖动**

**问题**：鞋子穿上后不停上下抖动

**原因**：物理体冲突
- 鞋子创建时使用了 `this.physics.add.sprite()` → 有物理体，受重力影响下落
- `ItemManager.update()` 每帧用 `setPosition()` 强制设置位置
- 两者冲突 → 抖动

**修复方案**（在 `ItemManager.js` 的 `attachVisual()` 中）：
```javascript
attachVisual(itemSprite, player, bodyPart, offset) {
    // ⚠️ FIX: 禁用物理体防止和 setPosition 冲突导致的抖动
    if (itemSprite.body) {
        itemSprite.body.enable = false;  // 禁用物理体，不再受重力/速度影响
    }
    
    this.attachedVisuals.set(itemSprite, { player, bodyPart, offset });
}
```
