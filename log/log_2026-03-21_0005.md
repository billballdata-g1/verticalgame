### **问题回顾**（历时约 12 小时）

从 2026-03-20 下午开始，遇到一个顽固的 bug：
- ✅ HP 数字正常显示和变化 (`HP: X/100 | Enemy: Y/60`)
- ❌ 血条宽度完全不变化（始终满条）

**已尝试的方案（全部失败）**:
1. `.setOrigin(0)` — 让 Rectangle 左端固定
2. `setPosition()` — 敌人血条跟随移动
3. `setScale()` — Phaser 官方推荐的方法
4. 直接修改 `.width` 属性
5. 检查 depth/zIndex、alpha、visible 状态
6. 强制刷新浏览器、重启 Vite
7. 添加大量 console.log 调试输出

---

### **🔍 突破时刻**（2026-03-20 23:40）

用户提出了一个关键建议：
> "可以用血量是很多小块排成队列，碰到了就消失几块"

这个思路完全跳出了原来的框架！不是让一个矩形缩放，而是用**多个独立的小方块拼接**。每掉一次血，右侧的几个小方块 `setVisible(false)` 隐藏起来。

---

### **📐 新方案实现**

#### **常量定义**（全局作用域）
```javascript
const HP_PER_BLOCK = 5;            // 每个小方块代表多少血量
const PLAYER_MAX_BLOCKS = 20;      // 100HP / 5 = 20 blocks
const PLAYER_BLOCK_SIZE = 12;
const ENEMY_MAX_BLOCKS = 12;       // 60HP / 5 = 12 blocks
const ENEMY_BLOCK_SIZE = 8;
```

#### **血条创建**
```javascript
// 玩家血条（左上角）
this.playerHealthBlocks = [];
for (let i = 0; i < PLAYER_MAX_BLOCKS; i++) {
    const block = this.add.rectangle(
        PLAYER_BAR_X + i * PLAYER_BLOCK_SIZE,
        PLAYER_BAR_Y,
        PLAYER_BLOCK_SIZE - 1,   // -1 留小间隙
        PLAYER_BLOCK_SIZE,
        0x00ff00                 // 绿色
    ).setOrigin(0.5);
    
    block.setDepth(999);         // 确保在最上层
    this.playerHealthBlocks.push(block);
}
```

#### **血条更新**（每帧）
```javascript
const playerVisibleBlocks = Math.max(0, Math.ceil(this.playerHP / HP_PER_BLOCK));
for (let i = 0; i < PLAYER_MAX_BLOCKS; i++) {
    this.playerHealthBlocks[i].setVisible(i < playerVisibleBlocks);
}
```

### **🎯 额外修复：敌人死亡残留血条**

**问题**：敌人被 `destroy()` 后，头顶的红色小方块还残留 3 个。

**解决**：在敌人死亡时同时清除所有血条方块
```javascript
const hideEnemyHealthBar = () => {
    this.enemyHealthBlocks.forEach(block => block.setVisible(false));
};

// 敌人死亡时调用
if (enemy.hp <= 0) {
    enemy.destroy();
    hideEnemyHealthBar();     // 🔴 隐藏所有血条方块
}
```
